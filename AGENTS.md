# AI / Research Worker Contract

For any substantial research in this repository:

1. Read `RESEARCH_OS.md` and `research/STATE.md` before deep work.
2. Treat chat context as transient and Git state as durable.
3. Do not redo completed work merely because a conversation was interrupted.
4. During long research, persist meaningful, expensive-to-reconstruct progress to `research/STATE.md` before moving into another large branch.
5. Do not checkpoint every search or tiny thought; checkpoint meaningful research state changes.
6. Keep source-reported facts, inference, and unresolved uncertainty distinct.
7. Preserve enough identifiers/links/details that another worker can reproduce the path.
8. Before ending an incomplete research session, leave a concrete **NEXT EXACT ACTION**.

The overriding goal is simple: **an interrupted model run must not erase the research already accomplished.**
