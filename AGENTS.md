# AI / Research Worker Contract

For any substantial research in this repository:

1. Read `RESEARCH_OS.md` and `research/STATE.md` before deep work.
2. Treat chat context as transient and Git state as durable.
3. Do not redo completed work merely because a conversation was interrupted.
4. **Write sparingly.** GitHub is not a live scratchpad or token-by-token research log.
5. Research for a substantial stretch first; batch multiple related discoveries into one coherent checkpoint.
6. Do not checkpoint a single search, paper discovery, duplicate result, tentative idea, or minor clarification.
7. Persist only when the accumulated state would be meaningfully costly to reconstruct, at a natural handoff, or before a major research branch change.
8. Keep source-reported facts, inference, and unresolved uncertainty distinct.
9. Preserve enough identifiers/links/details that another worker can reproduce the path.
10. Before ending an incomplete research session, leave a concrete **NEXT EXACT ACTION**.

The overriding goal is simple: **an interrupted model run must not erase valuable research, while normal research should incur as few Git writes as possible.**
